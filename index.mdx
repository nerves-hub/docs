NervesHub delivers signed firmware updates to connected devices and gives you remote access to them. You can run it yourself or use NervesCloud, the hosted service. This documentation covers both.

## Set up a project

<Steps>
  <Step title="Add NervesHubLink to your project">
    Add `{:nerves_hub_link, "~> 2.14"}` to your Nerves project's `mix.exs` and point it at your NervesHub host. See [Add to your project](/setup/add-to-project).
  </Step>
  <Step title="Authenticate the device">
    Use a [shared secret](/auth/shared-secret) to get started, or [device certificates](/auth/device-certificates) for production.
  </Step>
  <Step title="Install the CLI">
    Install the `nh` CLI and sign in with `nh user login`. See [CLI installation](/cli/installation).
  </Step>
  <Step title="Create a signing key and upload firmware">
    Run `nh key create my_app_key`, build with `mix firmware`, then sign and upload with `nh firmware upload --key my_app_key`. See [Firmware](/setup/firmware).
  </Step>
  <Step title="Create a deployment group">
    Target devices by tag and version, point the group at your firmware, and turn it on. See [Deployment groups](/setup/deployments).
  </Step>
</Steps>
